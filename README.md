# School Website Demo

A visually elite school website for a school with 8 campuses, built with React, Next.js, Tailwind CSS, Framer Motion, and @upendra.manike/next-motion-kit.

## Features
- **8 Campus Showcases**: Animated showcase sections for each campus.
- **Scroll-Triggered Reveals**: Dynamic loading and reveals.
- **Staggered Entrances**: Smooth staggered animations for elements.
- **Next.js & Tailwind**: Modern, fast, and responsive UI.

## Getting Started

1. Clone the repository.
2. Run `npm install`.
3. Run `npm run dev` to start the development server.
